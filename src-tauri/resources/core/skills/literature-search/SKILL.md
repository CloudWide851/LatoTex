# Literature Search

## Evidence workflow

1. Clarify the research question, population or domain, outcome, date range, and exclusions when they materially change retrieval.
2. Search local bibliography evidence first, then academic providers. Treat general web results as supplemental.
3. Prefer DOI, arXiv ID, and stable provider IDs over title matching. Merge duplicate records without discarding provider provenance.
4. Label support as `metadata`, `abstract`, or `fulltext`. A title alone never supports a claim about methods or conclusions.
5. Report confirmed facts, metadata-only signals, model inference, and unresolved uncertainty separately.

## Output contract

- Cite the source provider and stable identifier for each important record.
- Preserve author, year, venue, open-access status, and landing or PDF links when verified.
- Explain partial provider failures without exposing transport details.
- Never invent a paper, identifier, abstract, result, or conclusion.
- Suggest a narrower query or full-text check when the available evidence is insufficient.
